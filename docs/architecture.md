## 模块职责

### 1. backend.models — AI 模型接入层
- 定义统一的 BaseLLM / BaseEmbedding 抽象接口
- 为 DeepSeek、KIMI、OpenAI 等模型提供适配器
- ModelRegistry 管理模型生命周期与运行时切换
- Fallback 机制保障高可用

### 2. backend.core — 核心引擎
- ResearchAgent: ReAct 模式智能体，协调各模块
- MemoryStore: 短期（对话上下文）+ 长期（持久化）记忆
- CodeSandbox: 隔离的代码执行环境

### 3. backend.analysis — 专业数据分析
- GNSS 位移: 时间序列分解、突变检测、速率估计
- InSAR 形变: 形变场插值、累积形变分析
- 水文数据: 雨量、地下水位、孔隙水压力

### 4. backend.retrieval — 知识检索
- VectorStore: ChromaDB 驱动的语义检索
- 文档解析（PDF/TXT/MD）→ 分块 → 向量化 → 检索

### 5. backend.reporting — 报告生成
- Jinja2 模板引擎 → HTML → PDF
- python-docx → Word 报告
- Plotly 交互式图表 + Matplotlib 出版级图表

### 6. backend.self_growth — 自我成长
- 反馈收集与处理
- 记忆权重优化（用户反馈 + 时效衰减）
- Prompt 自动优化（APE 方法）
- LoRA 微调管线

## 数据流

### 对话流程
```
用户输入 → ResearchAgent → RAG检索(可选) → LLM调用 → 记忆存储 → 响应
```

### 分析流程
```
用户查询 → NL2Code → 沙箱执行 → 结果解析 → 图表生成 → 响应+可视化
```

### 反馈学习流程
```
用户反馈 → 反馈数据库 → 记忆权重更新 + Prompt优化 + 微调数据构建
```

## 技术栈选型

| 组件 | 技术选择 | 选型理由 |
|------|----------|----------|
| 后端框架 | FastAPI | 异步高性能、自动 OpenAPI、Python 生态 |
| 数据库 | SQLite → PostgreSQL | 开发零配置，生产可扩展 |
| 向量数据库 | ChromaDB | 本地轻量，无需独立服务 |
| Embedding | BAAI/bge-small-zh-v1.5 | 中文最优，384维，速度快 |
| 前端(初版) | NiceGUI | Python 原生，快速迭代 |
| 前端(移动) | TBD (Flutter/RN) | 根据需求后期决定 |
| AI框架 | LangChain + 自定义 | 灵活性高于纯 LangChain |
| 微调 | LoRA + PEFT | 显卡友好，快速迭代 |
| 沙箱 | subprocess → Docker | 开发→生产逐步增强 |
